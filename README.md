# Basic Chatbot

## Project Overview
A simple rule-based chatbot developed using Python.
It responds to predefined user messages.

## Features
- Greets the user.
- Responds to common questions.
- Provides help instructions.
- Handles unknown messages.
- Exits when the user types bye.

## Technologies Used
- Python 3
- Functions
- If-elif-else statements
- While loops
- Strings and user input

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run:

   python chatbot.py
